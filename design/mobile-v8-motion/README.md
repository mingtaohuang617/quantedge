# QuantEdge Mobile v8 Motion Review

独立的 24 秒竖屏动效验收工程，用于验证四个关键移动端交互：

- 系统与数据状态
- 评分列表进入详情
- 告警解决与撤销
- 更多中心与应用更新

运行 `npm run dev` 后在 Remotion Studio 中打开 `QuantEdge-Mobile-v8`。工程不被生产应用引用，不增加线上包体积。

## Commands

**Install Dependencies**

```console
npm i
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
