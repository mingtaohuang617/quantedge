## 重要实际发现

### 股票：股数估计有条件开放，其他限制保留

原规则要求估值日股数，过于苛刻。本轮增加可选 `latest_disclosed` 研究规则：股数须不早于查询时点 45 天、已公开、有来源、确认为当时最近披露值，并复核资本行动至报价日。45 天是明确记录的研究上限，尚未校准，也未修改生产权重或直接用于全市场。

MSFT 封面股数比前轮期末股数新，但没有自动宣称它是估值时点精确股数。官方 Nasdaq 接口请求与响应已存证：正确日期参数下返回 0 条记录，不能用 HTTP 200 当作取得有效价格。现有 Yahoo Close 仍保留供应商口径限制；总质量分继续为空。

### ETF：本次缺字段不能沿用旧成功结果

TQQQ 2026-09-17 发行商响应不含有效 30 日价差，费率和跟踪数据仍可核验。解析器现在保留有效字段，明确缺失；本地待发布产品快照更新到 09-17，产品覆盖率由旧快照 100% 变为 65%，产品分为空。EWY、RKLX 均为 60%，缺对应有效跟踪序列。

底层资产评价、产品执行质量、行情趋势与每日重置路径继续分开。没有从资产规模推算流动性，没有用价格回报冒充净值总回报，也没有把杠杆乘数当成持有期收益倍数。

显式 `evaluationAsOf` 会阻止加载未来日期的产品快照及已核验分类覆盖。但历史成员、原始分类是否在当时可得仍须独立认证，本轮没有把日期过滤称为完整历史成员库。

### 加密：真实样本的后期结果不支持提高权重

采集区间为 2024-01-01 至 2026-09-14，UTC 自然日，每品种 988 根日线。品种为 BTC、LTC、ETH、SOL、ADA、AVAX、DOT、ATOM、NEAR、ALGO，均为 Coinbase USD 现货。数量与完整性不代表全市场覆盖；研究分类为人工预先分组，不是历史分类数据库。

- BTC、LTC 的货币类组仅两个样本，不借用其他类别凑足八个。
- 八个网络类资产按同一 UTC 日期重算趋势，使用信号日前的历史；次日收盘进入，持有 20 个日区间，窗口不重叠，跨开发/保留边界的窗口剔除。
- 前 70% 日期用于开发区间，后 30% 为后期保留区间。没有在看到结果后挑选权重或划分。
- 开发区间 23 个窗口，平均秩相关约 0.045；后期 13 个窗口约 -0.069。这不是显著性检验，也不能证明所有加密资产的趋势因子无效。
- 单边成本 0、10、25、50 bps 分别计算净收益。相同成本的单调变换不改变横截面秩相关，不能把四个成本场景当四份独立有效性证据。
- 成交量只代表 Coinbase 单一现货场所的基础币数量，不冒充全市场流动性；不含质押、融资、永续合约收益及链上基本面。

原始响应不可变归档；重放会校验哈希、重复冲突、OHLC、日历和标准化记录，拒绝填补缺失交易日。修改历史数据的回归测试确认会阻断。

### 校准：结论是维持，不能从敏感性选择“最优”

当前美国股票快照中，105 个可计算质量与趋势的样本参与权重敏感性诊断。质量权重 30%、40%、70% 相对当前 60% 的排序相关约为 0.944、0.967、0.975。它只衡量排序变化，不衡量预测收益。六个分项的当前横截面成对相关没有达到本轮预设的绝对值 0.85 冗余提示线；单期未触发不能证明长期无冗余。

现有质量 60% / 趋势 40% 及子因子权重保持不变。保留集结果已被用于诊断，未来若据此调参，必须另外保留未看过的最终测试区间，不能继续称这段是独立最终测试集。

## 用户界面 Before / After

- Before：显示可计算分数与数据覆盖率，模型验证状态不够直观；切换权重时顶部 CountUp 暂时显示旧分数到新分数的中间值。
- After：显式显示“实验性研究，尚未通过完整样本外验证”；解释覆盖率不是准确率；未关联一手分类来源时提示待核验；顶部评分即时与算式一致，评分环动效保留。
- 移动端“全部”列表曾先加载美股、再补其他市场重排，实测出现约 0.74 的本地累计布局偏移。现在“全部”在各市场齐备后一次展示；单市场仍优先加载。两次复测该流程偏移约为 0–0.001，加入小于 0.1 的浏览器回归断言。认证页仍不加载完整行情。
- AI 解读拒绝 ETF/加密综合分、缺失分数、版本不一致和算式不一致，禁止宣称已验证有效，不再使用旧“规模代理流动性”模板。没有调用付费模型测试；采用确定性提示和拒绝路径测试。

- 本地 performance 记录为无节流 Chromium + 离线数据快照，仅作为页面观察；不是 Lighthouse 或真实用户 INP 验收。无生产压测或生产运行监控。
- 原始 SEC、Coinbase、Yahoo、Nasdaq 与产品来源证据位于忽略目录 `backend/data`；Git 中保留报告与引用，迁移需另行保存原始归档。发行商日缓存本轮另存为不可变包装归档，包装归档时间与源观测日期分别记录。

## 剩余外部依赖与关闭条件

| 缺口 | 必需内容 | 关闭条件 |
|---|---|---|
| 股票历史面板 | 历史上市/退市成员、当时行业、原始公开财务及修订、公司行动、可核验价格 | 不使用今天的幸存股票池；历史时点抽检通过，收益与财务口径可重放 |
| ETF 产品面板 | 各产品历史费率/价差、公司行动调整后 NAV、目标基准每日序列，包含逆向及单股/指数杠杆 | 同币种、同交易日、同收盘约定、正确收益基准的逐日匹配，足够样本检验 |
| 加密基本面与覆盖 | 历史交易品种、交易所成本与深度、网络/供给/解锁/安全数据 | 类别适配、有时点版本、没有用当前链上状态回填历史 |
| 最终有效性验证 | 固定评估方案、交易成本、未参与调参的测试样本、稳定性与不确定性评估 | 先冻结门槛再评估；结论可以是不支持当前模型，而非强行得到高分或盈利结果 |

这些依赖没有用合成数据、当前快照或评分可计算性替代。当前已有公开数据不足以关闭上述条目；没有购买数据或开通付费资源。
