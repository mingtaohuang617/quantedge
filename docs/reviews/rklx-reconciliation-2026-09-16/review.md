# RKLX 收益口径核查与研究准入

核查日期：2026-09-16。新行情截止 2026-09-15；旧库 RKLX 截止 2026-09-01。

## 结论

旧库 RKLX 分红前序列与“新供应商 Close 减去每股现金分配”的关系高度一致，直接相除会产生失真的投资收益。此结论支持隔离旧口径，不能据此断言券商原始行情错误，也不能用拟合公式覆盖旧数据。

新候选序列通过本轮日历检查，但独立成交价/NAV、完整现金与拆股份额单位尚未认证。严格总回报准入继续关闭，评分权重不变。

## 分红与旧库价格

发行商表格和 2025 年分配公告均显示：RKLX 于 2025-12-30 除息，每股分配 5.94640256 美元。该日期晚于已经抽查的 2025-12-09 三拆一交易生效日。Yahoo 事件金额为 5.946 美元，相差 0.00040256 美元；原始值各自保留。

对 198 个分红前同日期收盘价拟合“旧价格 = a × 新 Close + b”：

- a = 1.000000091。
- b = -5.946401994 美元，与负的发行商分配金额相差约 0.000000566 美元。
- 最大价格残差约 0.00016664 美元。

结合项目 Futu 采集器使用 QFQ、官方复权公式包含乘法项和加法项，证据支持旧序列具有减去现金分配的前复权特征。但历史原始响应与当次复权因子尚未归档，无法还原每次采集和覆盖过程，因此这是证据支持的解释，不是上游流水的完整认证。

带减法项的价格并不保持比率收益：例如 6→7 的涨幅约 16.7%，若两端都减去 5.9，则 0.1→1.1 会显示 1000%。拟合偏移不能作为反向修复依据。

旧库存在 7 行非正 OHLC，虽然收盘价仍为正。新的研究检查会拦截这种情况。正的复权价格也可能有收益口径问题，因此仅通过 OHLC 检查仍不足以解除原有总回报阻断。

## 2026-05-08 大幅上涨

同一供应商、同一收盘日期比较：RKLX 从 35.3600 到 59.3000，上涨 67.7036%；RKLB 从 78.5800 到 105.4700，上涨 34.2199%，两倍为 68.4398%。两者差约 -73.62 bps。

这一结果说明大幅上涨与底层资产杠杆方向及量级相符。它不是发行商 NAV 的独立验证，也不是可直接录入产品评分的跟踪误差；仍需拆分市场溢折价、费用、收盘时点与数据差异。原始超过 50% 的提示保留，追加解释而不删除警示。
