# QuantEdge Mobile v8 设计与交互规范

版本日期：2026-08-29

## 结论

Mobile v8 将移动端从桌面页面的缩小版，调整为可连续操作的研究终端。核心变化不是增加装饰，而是统一系统返回、数据状态、操作反馈、导航层级和触控规范。十个页面均保留原有数据与业务逻辑，桌面布局不受影响。

## Before 与 After

| 维度 | Before | After |
|---|---|---|
| 导航 | 高频与低频页面并列，入口过多 | 五个主标签：评分、监控、日志、宏观、我的；六个低频工具进入「我的」中心 |
| 返回 | 部分详情依赖页面内返回按钮 | 详情和底部面板写入浏览历史，支持系统返回和浏览器返回 |
| 系统状态 | 在线、缓存、离线和更新状态不透明 | 统一状态胶囊与状态面板，明确数据来源、时间和下一步操作 |
| 操作反馈 | 处置、静音等动作完成后缺少反悔窗口 | 统一成功反馈并提供撤销入口 |
| 底部布局 | 页面操作栏可能与主导航竞争层级 | 主导航固定为最高页面级导航；页面操作栏使用内容层或详情层 |
| 触控 | 紧凑按钮存在误触风险 | 交互目标至少 44 × 44 px，并适配安全区 |
| 更新 | Service Worker 可立即接管 | 更新由用户主动触发，避免研究过程被突然刷新打断 |

## 设计原则

- 状态先于装饰：先说明数据是否实时、是否缓存、操作是否成功，再考虑视觉效果。
- 上下文连续：进入详情后保留筛选、排序和滚动位置，返回时继续原任务。
- 关键操作可撤销：告警处置、静音等高频动作提供短时撤销。
- 高频入口固定：底部仅保留五个主标签，低频研究工具集中在「我的」。
- 渐进披露：列表呈现判断所需信息，复杂参数和系统细节进入详情或底部面板。
- 动效解释状态：只用于进入、退出、加载、成功和错误反馈；减少动态效果模式下自动降级。

## 视觉系统

### 颜色

| Token | 值 | 用途 |
|---|---|---|
| bg-0 | #08090E | 页面底色 |
| surface | #13151E | 主卡片和导航 |
| up | #1ED395 | 上涨、成功、在线 |
| down | #FF6B6B | 下跌、危险、严重告警 |
| cyan | #5EE6E6 | 信息和辅助交互 |
| amber | #F5B53C | 警告、待更新 |
| brand | #818CF8 | 品牌和主选择状态 |

### 字体与数据

- 默认界面：DM Sans 与系统无衬线字体。
- 数字、价格和时间：JetBrains Mono，使用 tabular numbers。
- 编辑式关键指标：Fraunces，仅用于 P&L 和少量 Hero 数据。
- 最小正文保持可读，不用低对比度制造所谓高级感。

### 尺寸与层级

- 基础间距：8 px，允许 4 px 微调。
- 触控目标：至少 44 × 44 px。
- 页面卡片圆角：16 至 20 px；底部面板：顶部 24 px。
- 页面主导航：z 30；页面内粘性操作：z 20；详情覆盖层：z 40；底部面板：z 50；横屏图表：z 90。
- 主页面的底部操作不得使用 fixed bottom-0，避免覆盖主导航；仅详情覆盖层可使用固定操作栏。

## 导航与历史

- URL 使用 `?tab=` 表达当前主页面，刷新和分享后仍能恢复位置。
- 评分、因子挖掘、10×筛选、股票基因和日志详情进入时写入历史。
- 系统返回优先关闭当前详情或面板，再返回上一页面。
- 「我的」中心包含已固定工具、最近使用、外观、安装、更新和系统状态。

## 系统显示与反馈

- live：数据服务在线并已同步。
- cache：使用最近一次有效数据，同时显示更新时间。
- offline：网络不可用，保留只读能力并给出重试入口。
- loading：骨架或局部加载，不让整页跳动。
- error：说明失败范围和恢复动作，不使用只有颜色的错误提示。
- success：确认动作结果；可逆操作同时显示撤销。
- PWA 更新：发现等待中的 Service Worker 后提示用户，由用户决定刷新时机。

## 核心流程

### 评分

- 列表优先呈现代码、价格、变化、综合评分和关键支柱。
- 点击后进入全屏详情；初始状态保持列表，不再误进首个标的。
- 详情支持系统返回，横屏图表提供明确退出按钮。

### 监控

- 严重告警先于一般告警。
- 处置和静音后即时反馈，并提供撤销。
- 下拉刷新和同步状态有可见反馈。

### 日志

- 时间线、P&L 和快速记录处于同一任务流。
- 快速记录作为内容层组件，不与主导航争夺固定底部空间。
- 日志详情进入浏览历史，返回后回到原时间线。

### 宏观

- 顶部明确实时、缓存或离线状态。
- 温度、周期和因子异常保持编辑式信息层级。
- 刷新按钮达到触控尺寸并提供加载状态。

## 六个次级页面

- 回测：参数、运行、阅读结果形成三步流程；保留组合回测旋钮交互。
- 10×筛选：把赛道、候选和观察列表组织成清晰漏斗，并支持详情历史。
- 智能贝塔：统一应用栏和三步流程，重置操作可触达。
- 因子挖掘：统一数据状态、触控尺寸和详情返回。
- 复利：移除无功能的返回符号，使用真实应用栏和状态组件。
- 股票基因：统一添加入口、详情历史和系统返回。

## 可访问性

- 底部面板和横屏图表使用对话框语义，打开后聚焦，关闭后恢复原焦点。
- Tab 焦点限制在当前面板内，Escape 可退出。
- 分段控件支持左右方向键、Home 和 End，并采用 roving tabindex。
- 重要按钮提供可读标签；状态不只依赖颜色。
- 尊重 `prefers-reduced-motion`，关闭非必要动画和顺滑滚动。

## 性能预算

构建后执行 `npm run audit:bundle`。当前上限为：

- 应用壳：120 KB gzip。
- 评分页：45 KB gzip。
- 静态市场数据：130 KB gzip。
- Recharts 图表包：165 KB gzip。

下一阶段若超出预算，优先拆分静态市场数据和只在图表打开时加载 Recharts，不通过降低信息可读性换取体积。

## 验收结果

- Vitest：702 / 702 通过，共 37 个测试文件。
- Playwright：22 / 22 通过。
- 移动视口：iPhone SE、iPhone 13、Pixel 7、740 × 360 横屏。
- 覆盖：五标签导航、系统返回、底部面板、触控尺寸、横向溢出、状态反馈和 PWA 更新逻辑。
